# Corporate Case Law (CCL)

Corporate context for agents, **mined** from what the firm actually decided (tacit knowledge = the residual of written policy) and **admitted** only if it survives point-in-time replay. Born from studying the CLM paper (`docs/CLM_PAPER_NOTES.md`).

| File | What |
|---|---|
| `WORKLOG.md` | chronological log of everything done, including mistakes and corrections |
| `docs/ADR.md` | 25 architecture / method decisions |
| `RESULTS.md` | v2 results tables, auto-generated by `aggregate.py` |
| `RESULTS_v3.md` / `summary_v3.json` | v3 (hard world, beam miner, fair black box), generated by `aggregate_v3.py` from `runs_v3/` |
| `tests/test_smoke.py` | 6 fixed-seed regression tests (`OMP_NUM_THREADS=1 python3 -m pytest -q tests`) |
| `ccl_sim.py` | simulation (v3 code; `--world easy|hard`, `--miner schema|beam|tree|covering`) |
| `aggregate.py` | `runs/*.json` → `summary.json` + `RESULTS.md` |
| `runs/` | v2 grid (18 runs), produced BEFORE the v3 stricter-law fix (ADR-020); v3's easy world supersedes it · `runs_prefix/` = first v2 grid |
| `v1/` | superseded v1 code and results (numbers overstated; see WORKLOG 19 Oct) |
| `ecc_python_review.md` | ECC python-review that triggered v2 |
| `dbx/` | CCL end to end on Databricks (Delta time travel, UC functions, Lakebase branch per trial, FMAPI); results in `dbx/REPORT.md` |
| `whiteboard/` | Board 2 generator + `combined.excalidraw` (Board 1 CLM + Board 2 CCL) |

Reproduce:
```bash
for sd in 7 11 23; do for m in schema tree covering; do python3 ccl_sim.py --seed $sd --miner $m --out runs/${m}_s${sd}_b0.35.json; done; done
for sd in 7 11 23; do for b in 0.55 0.70 0.85; do python3 ccl_sim.py --seed $sd --miner schema --bad-renew $b --out runs/schema_s${sd}_b${b}.json; done; done
python3 aggregate.py && python3 whiteboard/ccl_board.py
# v3: xargs -P 7 -L 1 python3 ccl_sim.py < runs_v3/jobs_all.txt && python3 aggregate_v3.py
```

Current numbers = v3 (`RESULTS_v3.md`). Caveats: synthetic only; recovery metric changed post hoc (ADR-012, ADR-021); a fair black box matches CCL's accuracy, so CCL's claim is the governed, readable form, not accuracy.
